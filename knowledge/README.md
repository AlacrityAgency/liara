# پوشه‌ی knowledge

1. این پوشه نسخه‌ی ثبت‌شده‌ی مشخصات OpenAPI و کد CLI رسمی لیارا است و پشتوانه‌ی مرجع تحلیل API سُکان را فراهم می‌کند. / This folder is a provenance-tracked snapshot of Liara's official OpenAPI spec and CLI source, used as grounding for the API analysis.
2. این داده‌ها مرجع مستندات‌اند و زمان اجرای سُکان بارگذاری نمی‌شوند؛ نگاشت نهایی endpointها در `packages/liara-client/docs/api-matrix.md` آمده است. / It is reference material only: the runtime never loads it, and the final endpoint mapping is in `packages/liara-client/docs/api-matrix.md`.
3. آدرس منابع، زمان دریافت و hash هر فایل در `source-registry.json` و `sources/` ثبت شده است. / Source URLs, retrieval times and hashes of every file are recorded in `source-registry.json` and `sources/`.
4. پوشه‌های `sections/` و `bundles/` خروجی ابزار آماده‌سازی پژوهشی در `research/` هستند و با `prepare` بازتولید می‌شوند. / `sections/` and `bundles/` are generated by the research tooling in `research/` (the `prepare` command).
5. هیچ راز، توکن یا پروفایل احراز هویت محلی نباید در این پوشه قرار گیرد. / No secrets, tokens or local authentication profiles may be stored here.
